# 7. Сценарий демонстрации для жюри (6–7 минут)

Подготовка: `npm run dev`, браузер во весь экран, открыт `/login`. Если до этого что-то меняли — в «Сценариях» нажать «Сбросить демо-сценарии».

**0:00 — Вход (20 с).** «Авторизация серверная: пароли хранятся только хешем, сессия в httpOnly-cookie; собираем только логин — минимум данных по 152-ФЗ». Нажать «Руководитель производства».

**0:20 — Обзор (60 с).** «Руководитель видит одной фразой: линия работает с ограничением. Ограничение — механообработка: 98 %, очередь 22 заготовки, ожидание почти час». Показать полосу участков (цвет + иконка + подпись), KPI с трендами, график выпуска — переключить период на 30 дней: красная точка — отказ шпинделя ОЦ-3, план не выполнен 9 дней. Справа — «Узкие места и резервы»: рекомендации не шаблонные, каждая посчитана перерасчётом модели.

**1:20 — Цифровой двойник (60 с).** Клик по сегменту У-03. «Мнемосхема: поток в шт/ч, очередь на рёбрах, ограничение подсвечено». Переключить слой «Ожидание» — видно, где теряется время. Паспорт участка: мощность по формуле, эффективное время, стоимость операции и простоя.

**2:20 — Сценарий (90 с).** «Изменить» → редактор. Ресурсы ОЦ 4 → 5 → «Рассчитать». «Цикл сократился на 56 минут, но выпуск не вырос — линия и так выпускает всё, что запускается, а себестоимость +3,5 %. Ограничение переехало на ОТК». Переключить сценарий на «Пиковая нагрузка +15 %»: недовыпуск 47 шт/сут, цикл больше 4 часов. Затем «Пик: ОЦ-5 и ускорение ОТК»: план выполнен, себестоимость ниже базы.

**3:50 — Аналитика (45 с).** Структура времени цикла (ожидание доминирует), накопление очередей за сутки в пиковом сценарии, таблица чувствительности «±1 ресурс», сравнение всех сценариев с отметкой лучшего значения.

**4:35 — 3D-тур (80 с).** «Пик: ОЦ-5…» → «На схеме» → 3D-тур. «В цехе стало пять обрабатывающих центров — новый отмечен полосой; сигнальные колонны показывают статус по модели; изделия на полосе меняют вид: заготовка → корпус → коробка». Клик по метке 4: карточка с живыми метриками, кейс SMED, «Процесс» → возвращаемся в мнемосхему. Режим «Маршрут» — два шага экскурсии.

**5:55 — Гость и права (40 с).** Выйти → «Регистрация» нового пользователя: он получает роль гостя — доступен только тур, без финансов. Войти руководителем → «Пользователи» → выдать роль «Руководитель»: права меняются сразу.

**6:25 — Документация (20 с).** Папка `docs/`: требования с трассировкой к слайдам, архитектура, BPMN, UML, ER, карта точек интереса, план тестирования; 40 автотестов движка, хранилища и сервера авторизации.

## Вопросы, к которым стоит быть готовыми

- **«Это настоящая симуляция?»** Аналитическая модель производственной линии: формула G/G/c Кингмана–Сакасегавы, связь вариаций между участками, закон Литтла. Детерминирована и покрыта тестами; формулы — в `docs/02-architecture.md`.
- **«Где реальные данные?»** Все данные синтетические и помечены. Замена — три файла в `src/data/demo`, интерфейс не меняется.
- **«Почему без ERP/MES?»** Интеграции исключены ТЗ (слайд 12).
- **«Безопасность входа?»** scrypt, httpOnly-cookie, роли проверяет сервер, защита от перебора и CSRF (раздел 2.9). Для эксплуатации — HTTPS и отключение демо-учёток.
